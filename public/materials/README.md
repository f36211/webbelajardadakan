# TrifectaStudy — Folder Materi

Tempatkan file PDF materi pelajaran Anda di folder yang sesuai berdasarkan **kategori** dan **mapel**.

## Struktur Folder

```
public/materials/
├── ipa/
│   ├── kimia/
│   │   └── (letakkan file PDF di sini)
│   ├── matematika/
│   │   └── (letakkan file PDF di sini)
│   ├── biologi/
│   │   └── (letakkan file PDF di sini)
│   └── fisika/
│       └── (letakkan file PDF di sini)
├── ips/
│   ├── sosiologi/
│   │   └── (letakkan file PDF di sini)
│   ├── geografi/
│   │   └── (letakkan file PDF di sini)
│   └── ekonomi/
│       └── (letakkan file PDF di sini)
└── basic/
    ├── bahasa-inggris/
    │   └── (letakkan file PDF di sini)
    ├── bahasa-indonesia/
    │   └── (letakkan file PDF di sini)
    └── pai/
        └── (letakkan file PDF di sini)
```

## Kategori

| Kategori | Warna | Mapel |
|----------|-------|-------|
| IPA | Teal (#2a9d99) | Kimia, Matematika, Biologi, Fisika |
| IPS | Blue (#0075de) | Sosiologi, Geografi, Ekonomi |
| Basic | Orange (#dd5b00) | Bahasa Inggris, Bahasa Indonesia, PAI |

## Cara Pakai

1. **Letakkan PDF** di folder yang sesuai (kategori/mapel)
2. **Nama file** sesuka hati — sistem tidak menggunakan nama file untuk deteksi
3. **Buka aplikasi** — material akan otomatis terdeteksi dan muncul di Dashboard
4. **Klik** materi untuk membaca dengan Smart Reader

## Format yang Didukung

- PDF — ✅ Didukung (langsung dibaca sebagai dokumen)

## Contoh Penempatan

```
materials/ipa/kimia/stoikiometri.pdf           ← Kimia IPA
materials/ips/sosiologi/stratifikasi.pdf      ← Sosiologi IPS
materials/basic/bahasa-inggris/tenses.pdf     ← Bahasa Inggris
```
